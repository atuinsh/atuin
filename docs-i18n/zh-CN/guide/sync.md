# 设置同步

至此，Atuin 已经在存储和搜索你的 shell 历史记录了！但它还没有开始同步。要实现同步，你需要在同步服务器上注册。你的所有历史记录都经过端到端加密，因此服务器无从窥探你的数据。

如果你还没有账号，请先[注册](#register)。如果你已经注册过，请直接[登录](#login)。

**注意：** 如果你想使用[自托管服务器](../self-hosting/server-setup.md)，需要先设置好你的 `sync_address`。

## 注册 {#register}

```shell
atuin register -u <YOUR_USERNAME> -e <YOUR EMAIL>
```

注册完成后，Atuin 会为你生成一个加密密钥并保存在本地。登录其他机器时需要用到这个密钥，你可以通过以下命令查看它：

```shell
atuin key
```

请**务必不要**将此密钥透露给任何人！Atuin 的开发者绝不会向你索要密钥、密码，或 Atuin 目录中的任何内容。

如果你丢失了这个密钥，我们将无法提供任何帮助，因此建议你将它妥善保存在安全的地方，例如密码管理器中。

## 首次同步

默认情况下，Atuin 每小时会同步一次你的历史记录。你可以对此进行[配置](../configuration/config.md#sync_frequency)。

若要手动执行同步，请运行

```shell
atuin sync
```

Atuin 会尽量智能地处理同步，避免浪费数据流量。不过，如果你发现有数据缺失，请尝试运行

```shell
atuin sync -f
```

这会触发一次完整同步，由于需要处理历史记录，耗时可能会更长。

## 登录 {#login}

当你只在一台机器上登录时，Atuin 同步的作用相当于备份。这本身就很有用，但当你同步多台机器时，真正的魔力才会显现。

首先，请确认你已经[在同步服务器上注册](#register)，并记下你的密钥。你可以通过 `atuin key` 查看它。

然后，在新机器上安装 Atuin。安装完成后，使用以下命令登录：

```shell
atuin login -u <USERNAME>
```

Atuin 会要求你输入密码和密钥。

同步会在后台自动进行，你也可以手动执行同步：

```shell
atuin sync
```

或者，如果你发现有数据缺失，可以使用以下命令强制执行完整同步：

```shell
atuin sync -f
```
