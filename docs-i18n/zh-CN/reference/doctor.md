# doctor

## `atuin doctor`

此命令会尝试诊断常见问题，同时导出你系统的相关信息。

提交 issue 或寻求支持时，请附上该命令的输出内容。

输出示例：

```text
Atuin Doctor
Checking for diagnostics


Please include the output below with any bug reports or issues

atuin:
  version: 18.1.0
  sync:
    cloud: true
    records: true
    auto_sync: true
    last_sync: 2024-03-05 14:54:48.447677 +00:00:00
shell:
  name: zsh
  plugins:
  - atuin
system:
  os: Darwin
  arch: arm64
  version: 14.4
  disks:
  - name: Macintosh HD
    filesystem: apfs
  - name: Macintosh HD
    filesystem: apfs
```
