# info

## `atuin info`

This command shows the location of config files on your system

Example output:

```text
Config files:
client config: "/Users/ellie/.atuin/config.toml"
server config: "/Users/ellie/.atuin/server.toml"
client db path: "/Users/ellie/.atuin/data/history.db"
key path: "/Users/ellie/.atuin/data/key"
session path: "/Users/ellie/.atuin/data/session"

Env Vars:
ATUIN_HOME = None
ATUIN_CONFIG_DIR = None

Version info:
version: 18.1.0
```
